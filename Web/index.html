ABSTRACT / บทคัดย่อ

06016409 · PHYSICAL COMPUTING

ChronoDesk เป็นอุปกรณ์นาฬิกาตั้งโต๊ะที่พัฒนาขึ้นเพื่อให้ดูเวลา สภาพอากาศ และช่วงเวลาทำงานได้จากอุปกรณ์ตรงหน้า โดยไม่ต้องเปิดโทรศัพท์หรือสลับไปยังเว็บไซต์ระหว่างอ่านหนังสือหรือทำงาน ระบบใช้ ESP32-C3 Super Mini ควบคุมจอสี ST7735 และอ่านอุณหภูมิพร้อมความชื้นภายในห้องจากเซนเซอร์ SHT31 การเชื่อมต่อ Wi-Fi ใช้สำหรับซิงค์เวลาผ่าน NTP และดึงสภาพอากาศภายนอกบริเวณ KMITL จาก OpenWeatherMap ผู้ใช้สลับระหว่างหน้าภาพเคลื่อนไหว นาฬิกา สภาพอากาศ และ Pomodoro ด้วยปุ่มเดียว ตัวจับเวลากำหนดช่วงทำงาน 25 นาทีและพัก 5 นาที พร้อมเริ่ม หยุดพัก ทำต่อ และรีเซ็ตได้ โครงการเผยแพร่วงจร ซอร์สโค้ด ไฟล์เคสพิมพ์สามมิติ และแนวทางทำตาม เพื่อให้ผู้สนใจศึกษา ประกอบ และพัฒนาต่อได้ โดยระบุข้อจำกัดของเฟิร์มแวร์ปัจจุบันไว้อย่างชัดเจน

THE IDEA / จุดเริ่มต้น

ไม่ต้องเปิดอีกหน้าจอ เพื่อดูเรื่องใกล้ตัว

ปัญหาที่เจอระหว่างนั่งโต๊ะ

จะดูเวลาและสภาพอากาศที เรามักต้องเลื่อนเมาส์ไปมุมจอ เปิดมือถือ หรือเข้าเว็บไซต์อีกหน้า ระหว่างอ่านหนังสือ ถ้าจะใช้ Pomodoro ก็อาจต้องเปิดเว็บหรือวิดีโอ YouTube เพิ่ม ทั้งที่ใช้คอมพิวเตอร์ทำอย่างอื่นอยู่ หรือไม่ได้จ้องหน้าจอตลอด เราจึงอยากมีอุปกรณ์ตรงหน้าที่เหลือบดูข้อมูลและจับเวลาได้เลย

รวมไว้บนโต๊ะ ควบคุมด้วยปุ่มเดียว

ขั้นตอน 02 / 06

ต่อวงจรตามแผนภาพ

ต่อจอ เซนเซอร์ และปุ่มตามตารางพิน ตรวจชื่อขาบนโมดูลจริงก่อนจ่ายไฟ

  • ใช้ 3.3V และ GND ร่วมกัน ต่อ BLK ผ่านตัวต้านทาน 1 kΩ
  • SHT31: SDA ไป GPIO0, SCL ไป GPIO1; โค้ดตรวจ address 0x44 แล้ว 0x45
  • ปุ่มต่อ GPIO3 กับ GND โดยใช้ Pull-up ภายใน
  • ตรวจสายจ่ายไฟและไม่ให้ลัดวงจรก่อนเสียบ USB
ขั้นตอน 03 / 06

ติดตั้งเครื่องมือและไลบรารี

ติดตั้ง Arduino IDE และแพ็กเกจ ESP32 ของ Espressif ผ่าน Boards Manager จากนั้นเพิ่มไลบรารีผ่าน Library Manager

  • ArduinoJson
  • Adafruit GFX Library
  • Adafruit ST7735 and ST7789 Library
  • Adafruit SHT31 Library และ dependency ที่ Library Manager เสนอ
  • WiFi, HTTPClient, SPI, Wire และ time มากับ ESP32 core ไม่ต้องหาไลบรารีชื่อเดียวกันมาติดตั้งเพิ่ม
Arduino IDE ↗Espressif ESP32 ↗
ขั้นตอน 04 / 06

ตั้งค่าแล้วอัปโหลด

เปิด sketch ตั้งค่า Wi-Fi 2.4 GHz และ OpenWeatherMap ของคุณ เลือกบอร์ด ESP32-C3 และพอร์ตให้ตรง จากนั้น Verify และ Upload

  • แก้ ssid, password และ weatherApiKey ด้วยค่าของคุณเอง อย่านำข้อมูลส่วนตัวขึ้น repository
  • ค่า lat / lon เดิมเป็นบริเวณ KMITL; แก้ได้หากต้องการสถานที่อื่น
  • โค้ดตั้งเวลาไทย GMT+7 ไว้แล้ว ไม่มีหน้า setup Wi-Fi บนอุปกรณ์
  • Repository ไม่บันทึก board menu หรือ USB setting ที่ใช้จริง ให้ตรวจตามบอร์ดและ core ที่ติดตั้ง
  • ถ้าคอมไพล์หาเฟรมไม่พบ ให้ตรวจว่า header ทั้งแปดอยู่ในโฟลเดอร์เดียวกับ sketch
const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_WIFI_PASSWORD";
String weatherApiKey = "YOUR_OPENWEATHERMAP_KEY";

ค่าตั้งต้นสำหรับ ESP32-C3 Super Mini ที่ใช้ USB ในตัว — ตรวจพอร์ตและขนาดแฟลชให้ตรงกับบอร์ดจริง

พิมพ์และทดลองประกอบเคส

อ่านคู่มือพิมพ์เคสก่อน Slice ใช้ STL ที่ Scale 100% เคสจริงใช้ eSUN PLA+ สีดำบน Bambu Lab A1 mini หัวฉีด 0.4 mm

  • ไฟล์ประกอบด้วย front.stl, body.stl, rear.stl และ support.stl

  • support.stl คือแถบยึด 14 ชิ้น ใช้ infill 100% เฉพาะชุดนี้ ไม่ใช่ support ที่ slicer สร้าง

ขั้นตอน 06 / 06

ตรวจทั้งสี่หน้า

เปิด Serial Monitor ที่ 115200 baud หากต้องการดูสถานะ หลังเปิดเครื่องรอ Wi-Fi และข้อมูลเริ่มต้น แล้วทดสอบการแสดงผลกับปุ่ม

  • ค้างที่ Connecting WiFi... ให้ตรวจชื่อเครือข่าย รหัสผ่าน และ Wi-Fi 2.4 GHz; ปัจจุบันไม่มี timeout
  • กดค้าง 2 วินาทีเพื่อวน Animation, Clock, Weather และ Pomodoro
  • ถ้าเวลาไม่แสดง ให้ตรวจอินเทอร์เน็ตและ NTP; ถ้า SHT31 ไม่ตอบ ให้ตรวจไฟและ GPIO0/1
  • Outdoor เป็นศูนย์หรือข้อมูลเดิม ให้ตรวจ API key สิทธิ์ Current Weather อินเทอร์เน็ต และพิกัด
  • หน้า Pomodoro: กดสั้นเริ่ม/หยุดพัก/ทำต่อ กดสองครั้งรีเซ็ต และต้องอยู่หน้านี้เพื่อให้เวลานับต่อ

สิ่งที่ควรรู้ก่อนทำตาม

อธิบายตามพฤติกรรมของเฟิร์มแวร์ที่เผยแพร่ เพื่อให้เห็นทั้งสิ่งที่ทำได้และสิ่งที่ยังพัฒนาต่อได้

ต้องเชื่อม Wi-Fi ตอนเริ่ม

เปิดเครื่องแล้วจะรอจนกว่า Wi-Fi เชื่อมต่อสำเร็จ ยังไม่มี timeout หรือหน้าแก้เครือข่ายบนอุปกรณ์

Pomodoro ต้องอยู่หน้าของตัวเอง

เปลี่ยนหน้าแล้วตัวจับเวลาหยุดนับ เมื่อครบช่วงจะเปลี่ยนโหมดแล้วรอให้กดเริ่มใหม่ ระยะ 25/5 นาทีแก้ได้จากโค้ด

Weather ใช้พิกัดในโค้ด

ค่าปัจจุบันเป็นบริเวณ KMITL ต้องมีอินเทอร์เน็ตเพื่อดึงข้อมูล การรอ API อาจทำให้จอและปุ่มตอบสนองช้าลง

ยังไม่มีสถานะข้อมูลล้าสมัย

จอยังไม่แจ้งข้อผิดพลาดหรือเวลาอัปเดตล่าสุด หากอ่านเซนเซอร์ไม่ได้อาจคงค่าล่าสุด และยังไม่มีผลทดสอบความแม่นยำที่บันทึกไว้ใน repository

แนวทางพัฒนาต่อ

ข้อเสนอต่อไปนี้ยังไม่อยู่ในเฟิร์มแวร์ปัจจุบัน: ให้ Pomodoro เดินเบื้องหลังและปรับเวลารอบได้ เพิ่มหน้าตั้งค่า Wi-Fi และการเชื่อมต่อใหม่ ตรวจ HTTP/JSON พร้อมแสดงสถานะข้อมูล ลดการขัดจังหวะจากการเรียก API และทดสอบความแม่นยำ การใช้พลังงาน และประสบการณ์ใช้งานอย่างเป็นระบบ
