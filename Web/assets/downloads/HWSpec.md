# Hardware ที่ใช้ในโปรเจกต์ ChronoDesk

| อุปกรณ์              | จำนวน   | สเป็ก                                            |
| -------------------- | ------- | ---------------------------------------------------- |
| ESP32-C3 Super Mini  | 1 บอร์ด | Wi-Fi 2.4 GHz, Bluetooth LE                          |
| จอ TFT IPS 0.96 นิ้ว | 1 จอ    | ไดรเวอร์ ST7735, ความละเอียด 80 × 160 พิกเซล, จอสี   |
| เซ็นเซอร์ GY-SHT31-D | 1 โมดูล | เซ็นเซอร์ SHT31 สำหรับวัดอุณหภูมิและความชื้นสัมพัทธ์ |
| ปุ่มกด Momentary     | 1 ตัว   | ปุ่มกดติด–ปล่อยดับ                                   |
| ตัวต้านทาน 1 kΩ      | 1 ตัว   | ต่ออนุกรม VCC กับขา BLK ของจอ TFT                    |
